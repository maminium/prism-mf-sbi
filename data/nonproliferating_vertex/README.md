# Non-proliferating pupal-wing model

`reference/summary_table.csv` is the per-wing summary we computed. The vertex files named in the `path` column are not included; see the deposit README.

`observations/` holds the observation vectors used for inference. `reference/theta_hat_w165.json` is the high-fidelity comparison reference. `lf_selection/` is the screening table for the twelve candidates. `results/posterior_runs/` holds the posterior samples.
