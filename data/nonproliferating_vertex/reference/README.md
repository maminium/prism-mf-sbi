# Reference quantities for the pupal-wing observation

| File | Role |
|---|---|
| `summary_table.csv` | Per-image processed geometry summaries (from VDat outlines) |
| `envelope.json` | Aggregation envelope / inclusion metadata for the w165 set |
| `theta_hat_w165.json` | Data-matched HF reference `θ̂≈(0.236, 0.351, 3.811)` used in Figs 6–7 |

`θ̂` is the high-fidelity parameter whose simulated summaries are closest to
`x_o` (not a laboratory measurement of the tissue parameters).
